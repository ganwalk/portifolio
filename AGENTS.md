# Portfólio de Armando Custodio

## Idioma

Toda comunicação, documentação, commit e PR deste projeto é em português do Brasil.

## Regra de copy inegociável

**Nunca use travessão (—), meia risca (–), hífen como pausa ou sublinhado (\_) em
qualquer texto visível.** É a marca registrada de texto gerado por máquina e este
portfólio existe justamente para provar o contrário. Use vírgula, ponto, dois
pontos, parênteses ou bullet (·).

Hífen e sublinhado seguem permitidos apenas como sintaxe de código: slugs de URL,
nomes de arquivo, chaves de storage, classes CSS.

Regras completas de tom e voz em `docs/tom-de-voz.md`. Arquitetura em
`docs/architecture.md`.

## Antes de escrever código

Leia `docs/architecture.md`. O projeto usa export estático (GitHub Pages), então
nada de recursos que dependam de servidor: sem middleware, sem rotas de API, sem
otimização de imagem no servidor.
